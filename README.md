# Gari Grill — приложение для заказа еды

Мобильное приложение для заказа еды (гриль/фастфуд) с самовывозом. В планах — доставка.

## Стек
- **Flutter** (Android, затем iOS), state management — `provider`
- **PocketBase** (self-hosted) — backend: БД, авторизация, файлы, realtime. Сервер будет размещён в РФ (152-ФЗ)

## Статус
Приложение целиком работает с локальным PocketBase:
- ✅ Меню: категории и блюда с фото из базы
- ✅ Новости и акции на главной (публикация, закрепление, срок действия, привязка к блюдам, просмотр фото с увеличением)
- ✅ Регистрация и вход (токен хранится на устройстве)
- ✅ Оформление заказа с сохранением в базу; серверная защита цен, номера и статуса
- ✅ История заказов; статус обновляется в реальном времени
- ⏳ Перенос на российский сервер, оплата, роль сотрудника и админ-панель

Подробный план, технический долг и заметки по разработке — в [ROADMAP.md](ROADMAP.md).

## Запуск

### 1. Backend (PocketBase)
1. Скачать PocketBase для своей ОС с [pocketbase.io](https://pocketbase.io/docs/) (используется версия 0.40.4) и положить бинарник в папку `backend/`.
2. Запустить из папки `backend/`:
   ```
   ./pocketbase serve --http=0.0.0.0:8090
   ```
   (в Windows PowerShell: `.\pocketbase.exe serve --http=0.0.0.0:8090`)
3. Админка: http://127.0.0.1:8090/_/ — при первом запуске создать суперпользователя (ссылка выводится в консоли).

При запуске PocketBase сам применит миграции из `backend/pb_migrations/` (создаст коллекции) и подхватит серверную логику из `backend/pb_hooks/`. Меню, новости и акции добавляются через админку. Для публикации новости нужно поставить галочку `is_published`.

### 2. Приложение
```bash
flutter pub get
flutter run                                              # эмулятор Android (адрес по умолчанию http://10.0.2.2:8090)
flutter run --dart-define=PB_URL=http://192.168.x.x:8090  # реальный телефон в одной Wi-Fi сети с компьютером
```
IP компьютера: `ipconfig` (Windows) или `ifconfig`/`ip a`. При первом запуске PocketBase Windows может запросить доступ в сеть — разрешить для частных сетей.

## Что в git, а что нет
В репозитории: код приложения, `backend/pb_migrations/` (схема БД), `backend/pb_hooks/` (серверная логика).
Не в репозитории (`.gitignore`): `backend/pocketbase.exe` и `backend/pb_data/` (база, пользователи, загруженные фото).

## Структура
```
lib/
  main.dart, config.dart
  theme/       — тема приложения и переходы между экранами
  models/      — auth, корзина, блюдо, новость, заказ
  services/    — клиент PocketBase и репозитории (меню, новости, заказы)
  screens/     — экраны
  widgets/     — общие виджеты (тосты, фон, просмотр картинок)
backend/
  pb_migrations/  — схема БД
  pb_hooks/       — серверная защита заказов (цены, номер, статус считает сервер)
```
