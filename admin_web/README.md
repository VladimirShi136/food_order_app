# Gari Grill — панель заказов

Отдельное Flutter Web-приложение для сотрудников ресторана. Панель подключается напрямую к PocketBase; клиентские и сотруднические аккаунты разделены.

## Локальный запуск

1. Запустить PocketBase из корня репозитория:
   ```powershell
   .\backend\pocketbase.exe serve --http=0.0.0.0:8090
   ```
2. Запустить панель в другом терминале:
   ```powershell
   cd admin_web
   flutter pub get
   flutter run -d chrome --dart-define=PB_URL=http://127.0.0.1:8090
   ```

Для открытия панели с другого устройства вместо `127.0.0.1` указать LAN-IP компьютера. После применения миграции создать учётную запись сотрудника в коллекции `staff` через локальную админку PocketBase. Публичная регистрация сотрудников закрыта.

Миграции добавляют отдельную auth-коллекцию `staff` и разрешают ей читать заказы. Серверный hook разрешает сотрудникам менять только статус и только по допустимым переходам. Superuser-доступ для ежедневной работы не используется.
